Скинулись TG Mini App

Мини-апп для компании друзей: создаёшь группу (поездка, квартира, вечеринка), добавляешь расходы — бот сам считает кто кому должен и минимизирует число переводов. Жадный алгоритм на балансах, FastAPI-бэкенд, верификация Telegram initData. Готовый прототип — WebApp-интерфейс с aiogram 3.

Vanilla JS Canvas API CSS Grid LocalStorage
