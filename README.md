# T3trix — Portfolio

Личный сайт-портфолио. Чистый HTML/CSS/JS — без сборщиков, без npm, без фреймворков.

**Live:** _задеплой на GitHub Pages и вставь ссылку сюда_

---

## Страницы

| Страница | Описание |
|---|---|
| `index.html` | Главная: hero, статистика, топ-3 проекта, стек |
| `projects.html` | Все 7 проектов с фильтрацией по типу |
| `about.html` | О себе, timeline, полный стек по категориям |
| `contact.html` | GitHub, Telegram, email, список всех репо |

## Структура

```
portfolio/
├── index.html
├── projects.html
├── about.html
├── contact.html
├── style.css        # общие стили, CSS-переменные, компоненты
├── main.js          # active nav, burger, fade-in on scroll
├── favicon.ico      # 16/32/48/64px
└── favicon-180.png  # apple-touch-icon
```
## Деплой на GitHub Pages

```bash
# 1. Создай репо portfolio (или используй любое другое имя)
# 2. Залей все файлы в корень ветки main
# 3. Settings → Pages → Branch: main → Save
# 4. Сайт появится по адресу:
#    https://T3trix-hub.github.io/portfolio
```
