Кто я

Обо мне

Привет. Я Алексей, разработчик который делает веб-сайты, приложения и Telegram-ботов. Работаю преимущественно на Python и Vanilla JavaScript — без тонн зависимостей, без магии фреймворков.

Мне интересно когда решение технически чистое: структура файлов понятна, алгоритм работает правильно, интерфейс не требует объяснений. Поэтому большинство фронтенд-проектов — без npm install вообще.

В Telegram-ботах люблю полноценную архитектуру: FSM, middleware, отдельные handlers — как в barbershop-bot. Во фронтенде — Canvas API вместо Chart.js, SVG вместо Leaflet, LocalStorage как замена бэкенду для демо.

Открыт к заказам и интересным задачам. Если нужен сайт, бот или интерактивный инструмент — пишите.
